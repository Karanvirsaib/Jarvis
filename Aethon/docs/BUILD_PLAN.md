# Aethon Build Plan

## Phase 1: Local foundation

- Choose the local model runtime.
- Verify model loading and inference.
- Build the basic chat loop.
- Add clean prompt formatting.

## Phase 2: Memory and personalization

- Add local memory storage.
- Save user preferences.
- Support remember and forget commands.
- Separate short-term and long-term context.

## Phase 3: Safe coding assistance

- Add code explanation and generation.
- Add file reading and summarization.
- Add file editing with approval.
- Never auto-run generated code by default.

## Phase 4: App control

- Add app launch and focus tools.
- Add approved workflow automation.
- Support safe UI interactions for known apps.
- Log important actions locally.

## Phase 5: Task planning and agents

- Add a task planner.
- Split goals into smaller steps.
- Track status and progress.
- Add approval checkpoints for risky actions.

## Phase 6: Workflow skills

- Create reusable skills.
- Add task templates.
- Add local document search and summary.
- Support custom user-defined workflows.

## Completion target

Aethon should become a private, local assistant that feels polished, JARVIS-inspired, and useful for everyday work.

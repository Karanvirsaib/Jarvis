# Aethon Roadmap

## Phase 1: Foundation

- local model runtime;
- chat loop;
- prompt formatting;
- basic memory.

## Phase 2: Productive assistance

- code explanation;
- code generation;
- safe file editing;
- file summarization.

## Phase 3: Desktop assistance

- app launch;
- app focus;
- workflow automation;
- approved local actions.

## Phase 4: Task agents

- goal planning;
- step execution;
- progress tracking;
- human approval checkpoints.

## Phase 5: Polishing

- voice support;
- reusable skills;
- local document search;
- stronger safety and UX.

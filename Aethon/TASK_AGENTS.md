# Aethon Task Agents

Task agents are focused helpers that work through a single goal step by step.

## What a task agent should do

- receive one clear goal;
- create a short plan;
- carry out approved steps;
- pause for approval when needed;
- report progress clearly; and
- finish with a concise summary.

## Good task examples

- set up a new workspace;
- review code changes;
- organize files;
- summarize a folder of documents;
- prepare a release checklist; and
- automate a repeated workflow.

## Agent behavior rules

- stay on the assigned task;
- do not expand scope without permission;
- do not hide failures;
- ask when instructions are unclear; and
- keep the user informed.

# Security Policy

## Reporting a security issue

If you find a security issue in Aethon, report it privately to the repository owner before posting it publicly.

## What to include

- a short description of the issue;
- steps to reproduce it;
- the impact you observed; and
- any suggested fix or mitigation.

## Security expectations

- Keep sensitive data local when possible.
- Require confirmation for destructive actions.
- Avoid executing untrusted code automatically.
- Make tool actions visible to the user.

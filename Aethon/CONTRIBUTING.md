# Contributing to Aethon

Thanks for helping improve Aethon.

## Principles

- Keep the project local-first.
- Prefer safe, explicit actions over hidden automation.
- Keep changes focused and easy to review.
- Avoid introducing cloud dependencies unless they are clearly optional.

## Good contributions

- improving documentation;
- adding tests;
- refining local assistant behavior;
- adding safe tools;
- improving task-agent workflows; and
- enhancing privacy and reliability.

## Before opening a pull request

- explain the problem being solved;
- describe the change clearly;
- keep the patch small when possible;
- include any relevant screenshots or logs;
- make sure the change does not weaken safety or privacy.

# Aethon

Aethon is a local-first, JARVIS-inspired AI assistant project.

It is designed to become a calm, capable, always-available assistant that can:

- answer questions conversationally;
- help write and explain code;
- control supported desktop apps and workflows;
- plan and coordinate multi-step tasks; and
- keep data and memory local whenever possible.

## Starter repository contents

This starter repo includes:

- a project vision and usage overview;
- a step-by-step build plan;
- a layered architecture outline;
- safety and privacy guidance; and
- task-agent expectations.

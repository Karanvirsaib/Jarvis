# Aethon Safety and Privacy

Aethon should be designed as a local-first assistant with clear safety boundaries.

## Safety rules

- Keep local processing as the default.
- Ask before destructive actions.
- Do not auto-run code unless the user explicitly allows it.
- Log important actions locally.
- Make it easy to review or undo work.
- Preserve a polished, trustworthy assistant personality without pretending to be human.

## Privacy rules

- Keep memory local whenever possible.
- Avoid unnecessary cloud services.
- Be explicit when any external service is used.
- Allow users to review stored memory and task history.
